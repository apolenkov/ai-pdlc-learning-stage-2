# Сообщение для ИИ-предпроверки

В OpenCode с корпоративным агентом откройте этот репозиторий и скопируйте:

```text
Проведи предварительное review изменения specification.md в текущей ветке относительно main. Прочитай README.md и review/request.md, затем изучи git diff main...HEAD -- specification.md и текущее содержимое документа.

Цель: при ошибочном вводе очищать предыдущий результат до «—» и указывать ошибочное поле. Нужен сценарий перехода от успешного расчёта к ошибке. Проверь сохранение четырёх исходных сценариев, согласованность требований и открытых вопросов, отсутствие несогласованных функций.

Верни конкретные замечания с местом в документе, причиной и предлагаемой правкой. Если замечаний нет, скажи, что проверено. Ничего не исправляй, не одобряй PR за людей и не объявляй программу протестированной.
```

Обсудите предложения, внесите принятые правки и сохраните коммит. Затем пройдите оба человеческих review из README.
