# Происхождение позднего старта

- Исходный репозиторий: `<фактический URL origin>`
- Исходная ветка эталона: `main`
- Полный SHA исходного baseline: `<40 символов из git rev-parse origin/main>`
- Исходный путь: `specification.md`
- Личная ветка R1: `course/<логин>/stage-1-error-result`

## Проверка R1 перед переходом в R2

- [ ] Сохранён сценарий обычной ставки.
- [ ] Сохранён сценарий нулевой ставки.
- [ ] Сохранён сценарий недопустимой суммы.
- [ ] Сохранён сценарий недопустимого срока.
- [ ] Добавлен сценарий «успешный расчёт → ошибочный ввод», включая ошибочное поле и результат «—».
- [ ] Решённый вопрос удалён; новых открытых вопросов для упражнения нет.

Полный SHA личного результата R1 получите после коммита командой `git rev-parse HEAD` и передайте вместе с веткой. Его нельзя заранее записать внутрь того же коммита.

Если baseline SHA недоступен, дерево грязное или содержимое не совпадает с показанным `origin/main:specification.md`, остановитесь. Не перезаписывайте файлы и не используйте запомнённый SHA.
